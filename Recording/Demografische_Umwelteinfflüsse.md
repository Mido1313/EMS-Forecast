## Kategorien für Parameter
- Wetter 
    - über API
    - in diversen Abständen

- Tag & Tageszeit bzw. Jahreszeit
    - manuelle Suche/Eintragung
    - Wochentag oder Wochenende
    - Uhrzeit
    - welche Saison


- Feiertage + Ferien
    - manuelle Suche/Eintragung
    - 13 Feiertage (ohne Sonntage)
    - Schulferien

- Events (ab x Besucher)
    - Recherche über große Events

- Baustellen
    - über API (mobilitydata) für Live-Abfrage
    - evtl. Recherche über Großbaustellen, der letzten 2 Jahre

- Verkehrsdaten
    - Staus & Unfälle über API (mobilitydata)
    - Pendlerparkplätze (manuelle Recherche)

- Bevölkerungsstatistik
    - Bevölkerungsdichte
    - Arbeitslosenstatistik
    - Alter der Bevölkerung 
    - Standorte der Pflegeheime

- Tourismus und Freizeit
    - Berge/Ausflugsgebiete
    - Seen

- aufbauend historische Daten der Einsätze
